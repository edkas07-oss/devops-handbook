# 🎯 Objectives

## 🔍 Overview

**Personal Site** dibangun bukan hanya sebagai website pribadi, tetapi juga sebagai media untuk membangun identitas profesional, berbagi pengetahuan, dan mendokumentasikan perjalanan sebagai seorang **IT Infrastructure** dan **DevOps Engineer**.

Halaman ini menjelaskan tujuan utama yang ingin dicapai melalui pengembangan project **Personal Site**, serta kriteria yang digunakan untuk mengukur keberhasilan implementasinya.

---

## 📌 Objectives at a Glance

Project **Personal Site** dikembangkan untuk mencapai beberapa tujuan utama berikut.

- 👤 Membangun identitas profesional yang dapat diakses secara publik.
- 📚 Membagikan pengetahuan dan pengalaman melalui artikel teknis.
- 💼 Menyediakan portofolio profesional dalam bentuk *Curriculum Vitae* (CV).
- 🚀 Membangun platform yang mudah dipelihara dan dapat dikembangkan secara berkelanjutan.

---

## 🎯 Primary Objectives

### 👤 Personal Branding

Membangun identitas profesional yang dapat diakses secara publik sebagai representasi pengalaman, keahlian, dan perjalanan karier.

### 📚 Knowledge Sharing

Membagikan artikel, pengalaman, serta pembelajaran yang diperoleh selama mengerjakan berbagai implementasi di bidang:

- Linux
- DevOps
- Cloud
- Container
- Automation
- IT Infrastructure

### 💼 Professional Portfolio

Menyediakan *Curriculum Vitae* (CV) yang selalu diperbarui sehingga memudahkan recruiter, calon klien, maupun rekan kerja untuk memahami pengalaman dan kompetensi yang dimiliki.

---

## ⭐ Secondary Objectives

Selain tujuan utama, project ini juga diharapkan dapat memberikan manfaat berikut.

- Meningkatkan kemampuan menulis dokumentasi teknis.
- Mendokumentasikan perjalanan belajar secara berkelanjutan.
- Menjadi referensi ketika mengembangkan project berikutnya.
- Menjadi media publikasi hasil implementasi maupun *Proof of Concept (PoC)*.

---

## 📈 Expected Outcomes

Project ini diharapkan menghasilkan beberapa keluaran berikut.

| Outcome | Description |
|---------|-------------|

## ✅ Success Criteria

Project dianggap berhasil apabila memenuhi kriteria berikut.

| Criteria | Description |
|----------|-------------|
| 🌐 Website Availability | Website dapat diakses melalui internet. |
| 👤 Professional Profile | Informasi pada halaman **About Me** selalu diperbarui. |

| 📄 Curriculum Vitae | Curriculum Vitae tersedia dalam format yang mudah diakses. |
| 🔧 Maintainability | Website mudah dipelihara dan dikembangkan. |
