# Getting Started

## 👋 Welcome

Selamat datang di bagian **How To**.

Bagian ini berisi panduan implementasi berbagai teknologi yang digunakan pada DevOps Engineering Handbook.

Setiap panduan dirancang agar dapat dipelajari secara mandiri dan digunakan kembali pada berbagai project. Fokus utama bagian ini adalah menjelaskan **cara menggunakan suatu teknologi**, bukan bagaimana teknologi tersebut diterapkan pada implementasi tertentu.

## ❓ Why How To?

Seiring bertambahnya jumlah project, dokumentasi implementasi teknologi sering kali berulang pada setiap project.

Dengan memisahkan dokumentasi ke dalam bagian **How To**, setiap teknologi cukup didokumentasikan satu kali sehingga:

- Lebih mudah dipelajari.
- Mengurangi duplikasi dokumentasi.
- Lebih mudah dipelihara.
- Dapat digunakan kembali oleh berbagai project.

## 📚 Scope

Bagian **How To** mencakup berbagai kategori teknologi yang digunakan pada DevOps Engineering Handbook.

| Category | Description |
| -------- | ----------- |
| Operating System | Instalasi, konfigurasi, dan administrasi sistem operasi. |
| Version Control | Penggunaan Git dan repository management. |
| Static Site Generator | Pembuatan dan pengelolaan static website. |
| Container | Container image, runtime, dan container management. |
| Web Server | Konfigurasi dan administrasi web server. |
| Automation | Tools dan workflow otomatisasi. |
| Monitoring | Monitoring, logging, dan observability. |
| OpenShift | Administrasi dan implementasi OpenShift. |
| Cloud Platform | Layanan dan integrasi cloud. |
| Tools & Utilities | Tools pendukung yang digunakan dalam berbagai project. |

Kategori tersebut akan terus berkembang seiring bertambahnya teknologi yang digunakan.
