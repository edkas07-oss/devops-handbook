# Hugo

Hugo adalah **Static Site Generator (SSG)** yang digunakan untuk membangun website statis dengan cepat dan efisien. Hugo ditulis menggunakan bahasa pemrograman **Go** dan dikenal karena proses build yang sangat cepat, sehingga cocok digunakan untuk dokumentasi, blog, personal website, maupun website perusahaan.

Pada dokumentasi ini, Hugo digunakan sebagai platform untuk membangun **Personal Site** yang nantinya akan dipublikasikan sebagai website statis.

---

## 🚀 Get Started

Panduan ini dirancang untuk membantu Anda mempelajari Hugo mulai dari proses instalasi hingga proses deployment website.

Seluruh panduan disusun secara bertahap sehingga dapat diikuti oleh pengguna yang baru mengenal Hugo maupun yang ingin membangun website statis dengan pendekatan yang terstruktur.

---

## ✨ Features

Hugo menyediakan berbagai fitur yang mempermudah proses pembangunan website statis, di antaranya:

- Build website dengan performa tinggi.
- Mendukung Markdown sebagai format penulisan konten.
- Memiliki sistem Theme yang mudah dikustomisasi.
- Mendukung struktur konten yang fleksibel.
- Mendukung pengelolaan menu dan navigasi.
- Mendukung Taxonomies seperti Tags dan Categories.
- Menghasilkan static website tanpa memerlukan database.
- Mudah diintegrasikan dengan Git dan GitHub.

## 📋 Prerequisites
