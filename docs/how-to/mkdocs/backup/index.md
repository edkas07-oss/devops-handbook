# DevOps Engineering Handbook

Selamat datang di **DevOps Engineering Handbook**.

Handbook ini merupakan dokumentasi seluruh implementasi, eksperimen, dan keputusan engineering yang dilakukan pada DevOps Lab.

## Tujuan

- Membangun personal knowledge base.
- Mendokumentasikan implementasi yang benar-benar telah diuji.
- Menyimpan troubleshooting dan lessons learned.
- Menjadi referensi untuk pekerjaan sehari-hari maupun pembelajaran.

## Ruang Lingkup

- Container Images
- Podman
- Automation
- CI/CD
- OpenShift
- Observability
- Security
- Architecture Decision Records (ADR)

## Prinsip

> **Experience → Implementation → Documentation**

Semua materi di handbook ini berasal dari implementasi nyata yang telah diuji di lab.
